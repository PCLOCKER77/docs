# 1. Purpose

This document defines the customer-facing release notes template for Digitize.

Customer release notes communicate approved product changes in clear, non-sensitive language suitable for customers, implementation partners, and support teams.

---

# 2. Scope

This template covers:

- Customer release summary.
- New capabilities.
- Improvements.
- Fixes.
- Known issues.
- Customer action required.
- Support contact guidance.

---

# 3. Out of Scope

This template does not define release approval, release scope, version assignment, rollout decisions, defect acceptance, or operational incident handling.

Customer release notes shall not expose internal architecture, security-sensitive details, exploit details, secrets, private operational procedures, or unapproved roadmap commitments.

---

# 4. Governing Standard

This document inherits `RN-00_Release_Notes_Standards.md`.

Customer release notes shall consume approved Release Management closure outputs and approved Product communication inputs.

# 6. Customer-Facing Language Rules

Customer-facing release notes shall:

- Use clear business language.
- Avoid internal implementation details unless approved.
- Avoid blame-oriented wording.
- Avoid exposing vulnerabilities or exploit paths.
- Avoid naming internal systems unless approved.
- Avoid promising future releases unless approved by Product.
- Identify customer action only when required.

---

# 7. Acceptance Criteria

This template is acceptable when:

- It is customer-readable.
- It consumes approved Release Management closure outputs.
- It avoids sensitive internal detail.
- It includes known issues and customer action where applicable.
- It does not decide release scope or approval.
